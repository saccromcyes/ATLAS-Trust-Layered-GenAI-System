      How these passages were chosen

      Keyword search (BM25) and meaning-based search (embeddings) each rank passages. Their rankings are merged with reciprocal rank fusion, then a cross-encoder rereads each passage with the question and gives the final relevance score.

      How well it works

      ATLAS is tested on a fixed set of questions: ones the documents answer, ones that need two facts combined, paraphrases that avoid the documents' wording, and questions the documents can't answer at all. The test runs automatically on every change.
